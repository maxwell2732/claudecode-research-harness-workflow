# 任务完成报告：CHARLS LTCI 扩展子样本提取（2011-2020）

## 任务背景

在原始 Zhang et al.（2026）复现子样本（charls_11，仅含 2011/2013/2018 三波，N=4,665）基础上，本次任务目标为：

1. **将样本扩展至 2020 波次**，使时间跨度更长（2011-2020），POST 期覆盖至 2020 年对所有 LTCI 试点城市生效。
2. **增加健康/人力资本结果变量**，供研究者检验 LTCI 政策对护理者多维健康和认知功能的影响。

触发原因：用户希望用同一 DiD 框架检验不同因变量（y），需要比劳动参与更丰富的结果变量集合。

---

## 执行过程

### 第一步：变量发现与编码核查

逐一扫描 2020 波次各模块的元数据（`metadataonly=True`），确认：

| 问题 | 发现 |
|------|------|
| 2020 无 Family_Transfer | 不可直接识别护理者；采用"曾为护理者"规则填充 |
| 2020 无 Health_Care_and_Insurance | HEALTH_INSURED 在 2020 置为 NaN |
| 2020 无 PSU 文件 | 沿用 2011/2013 PSU 建立的社区→城市映射 |
| 2018 CES-D 在 Cognition.dta | charls_11 将 2018 CES-D 错误标为缺失；本次修正 |
| 2020 DA003_N\_ 编码 | 1=已诊断，2=未诊断（非 notna 计数） |
| 2020 DC012_SN/DC028_SN 编码 | N-as-value 多选模式（N=选中，0=未选）；需用 ne(0)，非 eq(1) |
| 2011/2013 DC001S2/S3 方向定向编码 | DC001S2=2 表示月份正确（非 1）；需 notna() 而非 eq(1) |
| 2020 FA002_S2 农业就业 | 0=未受雇，2=受雇（被雇佣农业工人）；修正了 notna() 过度计数 |

### 第二步：编写 charls_13_ltci_ext_subsample.py

脚本：`scripts/charls_13_ltci_ext_subsample.py`

核心逻辑：
- 四波加载（2011/2013/2018/2020），波次专属模块映射
- 2018 波次额外加载 `Cognition.dta`，补充 CES-D 和认知变量
- 2020 护理者认定：在 2011/2013/2018 任一波中 IS_CAREGIVER_RAW==1 的个体，在 2020 波次中赋值为 1（"曾为护理者"规则）
- 新增 7 个结果变量（详见关键结果）
- 修正后保存至 `data/processed/charls_ltci_ext_subsample.parquet` 和 `.csv`

### 第三步：编写 charls_14_ltci_ext_codebook.py

脚本：`scripts/charls_14_ltci_ext_codebook.py`

为 35 个变量生成完整 codebook，含逐波均值、与论文均值对比（CLOSE/MODERATE/DIFFERS），以及新变量的跨波均值概览。

### 第四步：调试与修正（6 次迭代）

| 问题 | 修正 |
|------|------|
| DataFrame.between() 不适用 | 改为 `.apply(lambda s: s.between(1, 4))` |
| N_CHRONIC (2020) 计数过高（均值 13.4） | DA003_N\_==1 为已诊断，改用 eq(1) 替代 notna() |
| AGRI_EMPLOY (2020) 过高（46%） | FA002_S2==2 为被雇佣（非 notna）；修正为 eq(2) |
| 认知变量中"未参与测试→0"问题 | 增加 any_answered 掩码，未测试者返回 NaN |
| COGN_WORD_RECALL (2020) 均值 0.67 | DC012_SN 使用 N-as-value 编码，应 ne(0) 而非 eq(1) |
| COGN_ORIENT (2011/2013) 均值偏低 | DC001S2/S3 用 notna()，DC002/DC003 用 eq(1) |

## 研究使用注意事项

1. **波次固定效应必须包含**：各认知变量存在跨波测量工具差异，分析时必须加入波次虚拟变量。
2. **COGN_WORD_RECALL 2018 不可与其他波次合并**：2018 为 3 词测试，建议标准化（z-score within wave）后再使用。
3. **COGN_WORD_DELAYED 2020 量纲差异**：2020 延迟回忆较高，反映多次试验效应，非真实记忆改善。
4. **2020 护理者推断**：2020 的 IS_CAREGIVER_RAW 为推断值，使用 2020 数据时建议加入波次×护理者交互项进行稳健性检验。
5. **AGRI_EMPLOY 2020 定义略有差异**：使用 FA002_S2==2（被雇佣从事农业），与 2011-2018 的 FC001==1（受雇农业工人）含义相近但非完全一致。
